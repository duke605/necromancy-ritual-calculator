## Reading the results

The **Results** panel covers every ritual you set in the **Rituals** field. The **Focus** button above it shows the focus item. Select it to choose the ritual and focus item. Each list in the panel folds away when you select its title.

| List               | Contents                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| Rituals to perform | Each ritual and how many times to perform it.                                                   |
| Input              | The items the rituals use: focus items, ink, ectoplasm and, in Ironman mode, the ink materials. |
| Output             | The items the rituals make, and the souls they send to the Well of Souls.                       |
| Totals             | Costs, value, time, experience and disturbance chances, all added up.                           |

Hover over an item, or tap it, to see its prices. Hover over a ritual to see how long each one takes.

## Totals

| Total               | Meaning                                                                       |
| ------------------- | ----------------------------------------------------------------------------- |
| Input               | What the inputs cost at their current prices.                                 |
| Output              | What the outputs are worth at their current prices.                           |
| P&L                 | Output minus input. Green is a profit and red is a loss.                      |
| Rituals             | How many rituals there are in all.                                            |
| Disturbance chances | How many times a disturbance can appear. Which disturbances appear is random. |
| Duration            | How long all the rituals take.                                                |
| Experience          | The Necromancy experience from the rituals, without disturbances.             |

Items without a price count as 0 in the totals. See [Inventory and prices](/help/inventory-and-prices) to set one.

## Soul attraction and multiplier

**Soul attraction** is shown per ritual, as the game shows it, with five faces. One face lights up for each level reached: Low, Medium, High, Extreme and Dangerous.

**Multiplier** is how much more each ritual makes, from Multiply glyphs. For rituals that make necroplasm, a second figure includes the Underworld Grimoire.

## Settings

The settings in **Options**, under the **Rituals** field, change what the results include. They are saved, and apply to every ritual.

- **Take from inventory** removes the items you already have from the inputs.
- **Ironman mode** makes ink instead of buying it. See [Ironman mode](/help/ironman-mode).
- **No waste** rounds the added rituals up to their golden ratios. It only works in Ironman mode.
