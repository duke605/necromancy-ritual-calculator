## Your inventory

The **Inventory** page holds the items you have. With **Take from inventory** on, the calculator uses those items before it lists anything as an input.

In Ironman mode, the rituals use the inventory in the order you perform them, along with what the rituals before them make. Necroplasm you already have means fewer added rituals.

### Import from a bank screenshot

1. Take a screenshot of your bank in the game.
2. Paste it into **Import from bank**, drop it there, or select the area to choose the file.
3. Use the **Sync** and **Add** switch to choose what happens to your amounts. **Sync** sets them to the screenshot's. **Add** adds the screenshot's to yours.

The calculator reads the items and amounts from the screenshot. Select an item it found to correct it.

### Add or edit an item

- To add an item, select the **+** button beside the search field on the **Inventory** page.
- To change an amount, select the item and enter the new amount.
- To remove every item, select the red bin button beside the search field, then **Clear**. Your prices are kept.

## Prices

Prices come from the Grand Exchange. They update when you open the site, at most once an hour. To update them now, use the refresh button beside the search field on the **Inventory** page.

Items that cannot be traded have no Grand Exchange price. Basic ghostly ink and weak necroplasm start at 3 coins, their shop price. Other untradeable items count as 0 until you set a price.

### Set a price

You can set the price of any item in the results, whether you have it or not.

1. In **Results**, select the item under **Input** or **Output**.
2. Enter the price, or select the refresh button to get the current one.
3. To stop updates from replacing your price, select the lock.
4. Select **Save**.

To set the price of an item in your inventory, select it on the **Inventory** page.
